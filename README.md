# 🧠 JavaScript Challenges

A curated collection of JavaScript coding challenges focused on mastering core concepts through practical examples. These exercises cover a wide range of topics — from arrays and loops to advanced functions, the BOM/DOM, and regular expressions.

📂 **Project Structure**  
Each file/folder in this repository represents a standalone challenge:  
| File/Folder                              | Topic Covered                      |
| ---------------------------------------- | ---------------------------------- |
| `Array Challenge.js`                     | Array manipulation and methods     |
| `Arrow Function Challenge.js`            | Arrow function syntax and behavior |
| `Bom Challenge/`                         | Browser Object Model (BOM) tasks   |
| `Destructuring Challenge.js`             | Destructuring assignment in JS     |
| `Dom Challenge/`                         | Document Object Model (DOM) tasks  |
| `If Condition Challenge.js`              | Conditional logic with `if`        |
| `Loop Challenge.js`                      | Loop structures (`for`, `while`)   |
| `Map.js`                                 | `Map` object usage                 |
| `Number Challenge.js`                    | Working with numbers and methods   |
| `Operators Challenges.js`                | Arithmetic & logical operators     |
| `Practice.js`                            | Mixed practice tasks               |
| `Random Arguments Function Challenge.js` | Functions with dynamic arguments   |
| `Regular Expression Challenge.js`        | Regex patterns and usage           |
| `String Challenge.js`                    | String manipulation methods        |
| `Switch And If Condition Challenge.js`   | `switch` vs `if` logic             |
| `Variable_Concat_Challenge.js`           | Variable usage and string concat   |

🚀 **How to Use**  
1. Clone the repo
```
git clone https://github.com/Rana5Ahmed/JavaScript_Challenges.git
cd JavaScript_Challenges
```
2. Open in VS Code or your preferred editor.
3. Run individual challenge files in the browser console or Node.js to test and tweak.

🎯 **Purpose**  
This project was created to:  
• Reinforce JavaScript fundamentals  
• Offer real-world problem-solving practice  
• Prepare for interviews or technical assessments  

🛠️ **Technologies Used**  
• JavaScript (ES6+)
